Emby 缺集检测工具
================

以 TMDB 官方集数为准，找出 Emby 库中缺少剧集的剧。


##############################################################
方式一：Docker 部署（推荐，一次构建，以后一键启动）
##############################################################

【前提】装好 Docker Desktop 并让它保持运行
        https://www.docker.com/products/docker-desktop/

【启动】双击   启动docker.bat
        首次运行要下载镜像，等几分钟。
        跑完之后浏览器会自动打开 http://localhost:8787

【停止】双击   停止docker.bat

【看日志】命令行执行： docker compose logs -f

手动命令（不想用 bat 的话）：
       docker compose up -d --build      启动
       docker compose down               停止


*** Docker 部署最容易踩的坑：Emby 地址不要写 localhost ***

容器里的 localhost 指的是「容器自己」，不是你的电脑。
所以 Emby 地址要按你的实际情况填：

  场景 A：Docker 和 Emby 在同一台机器上（Docker Desktop）
          地址填  http://host.docker.internal:8096

  场景 B：Emby 在另一台机器/群晖上
          地址填  http://192.168.1.10:8096   （改成你的实际 IP）

  场景 C：Emby 也跑在 Docker 里，同一个 compose 网络
          地址填  http://容器名:8096

如果提示连不上 Emby，八成就是这个地址的问题。


【可选：预设配置，省得每次手填】
编辑 docker-compose.yml，把下面三项填上，然后重新 build：

    EMBY_URL: "http://host.docker.internal:8096"
    EMBY_KEY: "你的Emby API Key"
    TMDB_KEY: "你的TMDB API Key"

不填也行，在网页里填一样用。


##############################################################
方式二：本机直接跑（不需要 Docker，但要装 Node.js）
##############################################################

  1. 装 Node.js: https://nodejs.org/
  2. 双击   启动代理.bat
  3. 浏览器自动打开 http://127.0.0.1:8787

这种方式访问 Emby 可以用 localhost（因为直接在宿主机上跑）。


##############################################################
方式三：直接双击 HTML（最省事，但要给 Emby 开 CORS）
##############################################################

直接双击 emby-missing-episodes.html 也能用，但浏览器会直连 Emby，
需要设置：

  Emby 后台 → 网络 → CORS 主机  填  *   然后重启 Emby

注意：用 file:// 打开时浏览器发出的 Origin 是 null，
部分 Emby 版本即使配了 * 也会拒绝。这条路不保证成功。


##############################################################
填什么
##############################################################

  Emby 服务器地址   见上面「最容易踩的坑」
  Emby API Key      Emby 后台 → 高级 → API 密钥
  TMDB API Key      https://www.themoviedb.org/settings/api  （免费注册）

然后点「开始检测」。


##############################################################
结果说明
##############################################################

- 检测剧集数        本次扫描的剧集总数
- 存在缺集的剧      至少有一集缺失的剧
- 缺失总集数        所有缺集累加
- 完整剧集          一集不缺的剧
- 无法匹配 TMDB     TMDB 上搜不到的剧（中文名 / 别名 / 冷门剧）

表格中：
  绿块 = 已有该集      红块 = 缺失该集
  编号代表集数（E）

海报显示在剧名左侧（取自 TMDB，w185 尺寸，优先中文海报）。
TMDB 上没有海报的剧会显示一个灰底占位块（取剧名前两个字），不影响使用。
海报按需懒加载，并在浏览器缓存一天，翻页滚动不会重复请求。

特别篇（Season 0）不计入缺集判定；本地多出来的集数也不算缺集。

支持按剧名搜索、按「有缺集 / 连载中 / 已完结」筛选，并可导出 CSV。

结果会**三种方式**保存，任选其一或全都用：

  ① 服务器目录保存（推荐，经代理打开时自动生效）
    - 扫描完成后，页面自动把结果 POST 给代理，代理写入
      ./data/emby-missing-result.json
    - 下次打开页面（http://127.0.0.1:8787 或服务器地址）**自动加载**
    - 换浏览器、换电脑、换设备打开都能看到，无需手动操作
    - 清空按钮 / 「重新扫描」会同时删掉服务器上的这份结果
    - Docker 模式下挂载到宿主机 ./data，删容器重建也不丢

  ② 浏览器本地缓存（localStorage，自动）
    - 刷新页面、关掉浏览器再打开会自动恢复

  ③ 导出 / 导入文件（手动，最通用）
    - 扫描完成后自动下载一个 .json 文件（可在「扫完自动下载文件」取消）
    - 或随时点「保存到本地」按钮手动导出
    - 把 .json 文件**直接拖到页面上**即可加载，或点「加载本地文件」

  文件里包含剧名、每季缺失集号、海报、统计数字、扫描时间、Emby 地址，
  换台电脑、换个浏览器都能用。文件不大（3000 部剧约 400 KB）。

注意：localStorage 只在本浏览器有效，换浏览器或清数据就没了。
去掉「记住配置到本地」的勾选后，不再写入 localStorage（但服务器保存和
文件方式不受影响）。服务器保存只在**通过代理打开**时可用——直接双击
HTML（file:// 方式）没有服务器，只能用文件方式。


##############################################################
常见问题
##############################################################

Q: 之前检测很慢 / 一直卡住？
A: 曾经是因为默认的 TMDB 域名 api.themoviedb.org 在国内常被
   解析到 Meta 的 IP 段而无法访问，每次请求都要等 30 秒超时才失败。
   现在已改用 api.tmdb.org（走 AWS CloudFront，国内可直连），
   并且超时缩短到 12 秒、支持并发检测，速度快很多。

Q: Docker 里提示连不上 Emby？
A: 地址别写 localhost。用 host.docker.internal 或实际 IP。见上文。

Q: 想换 TMDB 域名 / 超时 / 端口？
A: 改 docker-compose.yml 里的环境变量，然后 docker compose up -d --build。
   本机方式则用 set 命令设置环境变量后启动。

Q: 显示「HTTP 401 —— API Key 无效」？
A: TMDB Key 填错了。去 https://www.themoviedb.org/settings/api 重新取。

Q: 扫描结果存在哪？重启服务器会丢吗？
A: 三种都存在，按可靠性排序——
   1) 服务器目录 ./data/emby-missing-result.json：经代理打开时自动存取，
      换浏览器/换设备都不丢。Docker 已挂载到宿主机 ./data，重建容器也在。
   2) 导出的 .json 文件：存在你磁盘上，最通用。
   3) 浏览器 localStorage：刷新/重开自动恢复，但换浏览器/清数据就丢。

Q: 拖入文件没反应？
A: 只支持 .json 文件。确认是本工具「保存到本地」导出的文件。
   如果提示"不是有效的扫描结果"，说明该 JSON 里没有 rows 数据。

Q: 自动下载的文件找不到？
A: 在浏览器「下载」目录里，文件名形如 emby-missing-2026-09-13-19-30-00.json。
   如果浏览器拦截了自动下载，会弹出提示，允许即可；也可手动点「保存到本地」。

Q: 海报加载不出来 / 显示灰色占位块？
A: 1. 这部剧在 TMDB 上就没有海报 → 显示占位块是正常的
   2. 确认 TMDB Key 有效（海报走 TMDB，Key 无效则拿不到海报）
   3. image.tmdb.org 被墙时海报加载不出，可设 TMDB_IMAGE_HOST 换镜像
